# Fast Bowls

A practice/demo build of a real-time "build your bowl" ordering site for a Lahori street-food concept — pick a base, protein, toppings and sauce and watch the bowl assemble live, layer by layer, before ordering. The demo runs on sample menu and order data while its Supabase backend is paused, so the menu, orders and staff dashboard are sample content for now, not a live backend.

Live demo: https://portfolio-kumailr.vercel.app/demos/fast-bowls/index.html (staff dashboard: https://portfolio-kumailr.vercel.app/demos/fast-bowls/admin.html)

`admin.html` is a demo staff dashboard for the kitchen side — orders, menu, and staff accounts — running on the same sample data.
